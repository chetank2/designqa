# Security Policy

## Supported Versions

We provide security fixes for the latest released version only.

## Reporting a Vulnerability

Please do **not** open a public issue for security reports.

Preferred method:
- Use GitHub Security Advisories to report privately.

If you cannot use GitHub advisories, contact:
- security@yourdomain.com

When reporting, please include:
- A clear description of the issue
- Steps to reproduce (or a proof-of-concept)
- Impact assessment (what an attacker can do)
- Affected versions or commit hash

## Response Timeline

We aim to acknowledge reports within 72 hours and provide a fix or mitigation
plan within 14 days, depending on severity and complexity.
